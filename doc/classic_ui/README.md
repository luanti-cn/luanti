# Java 经典风格 UI

启动后进入标题画面，通过单人游戏、多人游戏、云端与社区、选项四个入口导航。
世界列表、创建世界、连接服务器、暂停菜单及默认背包控件统一使用经典方块游戏的布局和配色。

| 范围 | 实现 |
| --- | --- |
| 标题画面 | 原创体素全景、缓慢背景移动、石质 Luanti 标志、黄色跳动标语 |
| 基础控件 | 灰色像素斜面按钮、黄色悬停文字、黑色输入框、深紫提示框 |
| 单人游戏 | 世界图标与双行信息、独立世界选项、保留游戏筛选及模组配置 |
| 多人游戏 | 居中服务器列表、独立连接页、保留搜索、收藏、注册及云端连接处理 |
| 设置 | 分类入口连接现有设置页，保留全部可配置项目 |
| 游戏内 | 居中暂停菜单、灰色默认背包面板与凹槽、九格默认快捷栏、像素生命与气泡图标 |
| 社区 | 保留本 fork 的云同步、好友、组队、私聊和内容管理入口 |

图案与字体由 `util/generate_classic_ui.py` 原创生成，使用 CC0 授权。
重建资源需要 Python、Pillow、fontTools 和 NumPy，运行 `python3 util/generate_classic_ui.py`。
背景采用完整体素体积的透视射线遍历，包含全部可见侧面和前景遮挡；相机没有横滚。
背景按窗口比例等比覆盖，水平漂移限制在窗口宽度的 2% 内。
全景资源通过规范化后的路径识别，兼容运行目录中包含 `bin/..` 的情况。
默认英文字体按整数像素栅格渲染；中文及其他缺失字形仍使用原有后备字体。

这是针对 Luanti 引擎和内置菜单的 Java 经典风格改造。游戏或模组提供的背包布局、HUD 数量、
字体、背景图片和显式颜色仍可覆盖默认外观，因此不声称所有游戏界面都与 Minecraft 逐像素一致。

## 验证

- CMake / Ninja 客户端构建通过，配置为 `RUN_IN_PLACE=ON`、`ENABLE_SOUND=OFF`、`ENABLE_GETTEXT=ON`。
- `./bin/luanti --run-unittests`：50 个模块、356 项检查全部通过。
- `xvfb-run -a ./util/test_singleplayer.sh`：单人游戏集成测试通过。
- 新增菜单回归规格共 9 项，使用本地轻量 Lua 测试运行器执行通过；规格兼容仓库的 Busted 工作流。
- `luacheck builtin`：修改文件无警告，仓库其余云端代码存在 7 条原有警告。
- 简体中文翻译通过 `msgfmt --check`；差异通过 `git diff --check`。
- 13 个生成资源重建后 SHA-256 完全一致。
- 1280×720 与 800×600：标题、世界列表可用；创建世界、世界选项、游戏内暂停与背包、
  设置及其返回流程、多人连接页、社区各入口已在实际客户端检查。
- 背景修复后另外检查了 1280×720、800×600、1280×600 的四边覆盖，以及连续动画帧的水平位移。
  背景生成器检查前景完整覆盖，重建后的 PNG 哈希一致；客户端重新构建和 356 项单元检查通过。

当前环境无法访问公共服务器列表和云服务；WebSocket 退回 REST 轮询。
云端账号、真实远程服务器登录以及其他平台未执行端到端验证。
